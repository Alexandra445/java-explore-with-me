# java-explore-with-me

Приложение ExploreWithMe («афиша» событий): основной сервис и сервис статистики.

Pull Request дополнительной функциональности: https://github.com/Alexandra445/java-explore-with-me/pull/4

## Состав проекта

- `ewm-main-service` — основной сервис (порт 8080).
- `ewm-stats` — сервис статистики:
    - `stats-dto` — общие DTO;
    - `stats-server` — HTTP-сервис статистики (порт 9090);
    - `stats-client` — HTTP-клиент для сервиса статистики.

## Запуск

```
docker compose up --build
```

Поднимает основной сервис, сервис статистики и по отдельной базе данных PostgreSQL для каждого.

## Дополнительная функциональность: комментарии

Пользователи могут комментировать опубликованные события, администратор модерирует комментарии.

Правила:
- комментировать можно только опубликованные события;
- автор может изменить и удалить только свой комментарий (изменение сохраняет дату правки);
- администратор может просматривать комментарии с фильтрами и удалять любой из них;
- в публичном списке новые комментарии идут первыми.

| Метод и путь | Доступ | Описание |
|---|---|---|
| `POST /users/{userId}/events/{eventId}/comments` | пользователь | добавить комментарий |
| `PATCH /users/{userId}/comments/{commentId}` | автор | изменить комментарий |
| `DELETE /users/{userId}/comments/{commentId}` | автор | удалить комментарий |
| `GET /users/{userId}/comments` | пользователь | свои комментарии |
| `GET /events/{eventId}/comments` | публичный | комментарии события |
| `GET /admin/comments` | админ | поиск (`eventId`, `userId`, `from`, `size`) |
| `DELETE /admin/comments/{commentId}` | админ | удалить комментарий |

Postman-тесты: `postman/feature.json`.
